# [Simple Calendar]


## 특징
- #### 개인 일정, 업무 일정 등 일정을 분리하고 싶을 때 사용 — 프로필별로 따로 관리
- #### 공휴일만 간단히 보여주며 짧은 메모와 날짜별 배경색 조절을 통한 간단한 일정 기획
- #### 매주/매월/매년 반복 일정
- #### 라이트/다크 테마 (시스템 설정 따라가기 포함)
- #### 오늘·내일 일정 알림 (하루 한 번, 시스템 알림 또는 앱 안 배너)
- #### 백업 내보내기/가져오기로 다른 기기에 일정 옮기기
- #### 좌우 스와이프·키보드(←/→, T)로 달 이동, 안드로이드 뒤로가기로 팝업 닫기


## 원리/기술
- #### HTML, CSS로 이미지 없이 자체 기능으로 디자인을 모두 해결
- #### 공공데이터포털 Open API를 통한 공휴일 정보 로드 (연 단위 1회 호출 + 기기 캐시)
- #### localStorage에 프로필별로 일정 저장 (구버전 데이터는 첫 실행 때 '기본' 프로필로 자동 이전)
- #### 서비스 워커로 오프라인 실행 (네트워크 우선, 실패 시 캐시)
- #### 안드로이드 WebView 앱으로 감싸 배포

## 개발
- 빌드 없이 정적 파일로 동작합니다. `python -m http.server 8080` 후 `http://localhost:8080`
- 테스트: `npm test` (Node 18+ 내장 테스트 러너, 의존성 없음)
- `core.js`: DOM과 무관한 로직(날짜 그리드, 공휴일 파싱, 반복 일정, 저장소) — 테스트 대상
- `script.js`: 화면과 이벤트
- 배포할 때 `service-worker.js`의 `CACHE_NAME` 버전을 올리면 이전 캐시가 정리됩니다.
